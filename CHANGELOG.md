# Changelog

## 0.1.6 — 2026-11-09

- 现有可选 Windows 原生选择器调试日志使用专属目录。插件启动及每 24 小时清理满 10 天的已关闭日志，使用文件句柄验证归属和占用，遇到权限错误留待下次检查。
- The opt-in Windows chooser trace now uses a dedicated directory. Startup and daily checks expire closed, identifiable traces after 10 days. Normal PDF scratch cleanup and saved exports use their existing lifecycle.

## 0.1.5 — 2026-11-09

- 修复切换、历史选择、刷新、关闭和卸载后的过期预览／错误覆盖；读取与独立导出任务分别管理。
- 将部分导出同意绑定已审阅快照；服务端生成文件前再次核对摘要，数据变化时拒绝继续。
- 明确可读正文、思考／工具过滤和附件引用范围，在 JSON 报告中加入兼容的 scope 字段。
- 精修原生主题配色、焦点、路径详情和短时入场反馈；增加中文／英文界面，尊重 reduced-motion。
- 增加真实 React/Edge 竞态测试及当前宿主生成的原生 Fork 合成回归；核心重放算法保持不变。

- Discard stale previews and errors across switching, history, reload, close and unmount; keep reads separate from submitted tasks.
- Bind partial-export consent to the reviewed snapshot and reject changed data on the server before creating files.
- Clarify readable-body scope and reference-only attachments; add an additive report scope field.
- Polish native theme controls, focus, path details and short entrance feedback with Chinese/English and reduced-motion support.
- Add real React/Edge race tests and synthetic native Fork regressions generated by the current host, without changing replay semantics.

## 0.1.4 — 2026-11-05

### DSH 0.2.2-rc.1 compatibility

- Add DSH Desktop **0.2.2-rc.1** to the verified host range; earlier versions retained.
- DSH 0.2.2-rc.1 refuses to load plugins whose `engines.dsh` does not name the running version, so 0.1.3 was skipped at boot on that host. This release is the load-compatible declaration, not a workaround.
- Verified on the real 0.2.2-rc.1 host: the session V4 reader, `sessionQuery.readSession`/`listSessions`, the exact `/api/ai-exporter.*` Fetch routes, TXT/Markdown/searchable-PDF output, round filtering, exclusive no-overwrite writes and single-use destination grants all behave as before. No engine, renderer or UI code changed.
- 73 automated regressions pass; no functional diff outside `package.json` and documentation.
